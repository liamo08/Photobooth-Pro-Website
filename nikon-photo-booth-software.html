Setup

How to Tether a Nikon Camera
to Your Photo Booth

What you need

  • A Windows 10 or 11 PC (64-bit) — laptop, mini PC or Windows tablet. See photo booth software for Windows.
  • A supported Nikon camera, ideally on its latest firmware.
  • A good USB cable for the camera’s USB port, plus a spare.
  • Mains power for the camera — a Nikon AC adapter with power connector (dummy battery) so it lasts the whole event.
  • A dye-sub printer such as a DNP, if guests get prints.
  • A touch screen and lighting — an LED panel or ring light keeps autofocus quick in dark venues.

How to set it up

  1. Install BoothLedger and start the free 30-day trial. Nikon’s camera software is included.
  2. On the camera: set the USB setting to MTP/PTP and turn off auto power-off.
  3. Close Nikon software (NX Tether, Camera Control Pro, Webcam Utility) — only one program can control the camera.
  4. Plug in by USB and select the Nikon in BoothLedger. Live view appears on the booth screen.
  5. Add your template and printer, then run a test batch of shots and prints before the event.

Can I use a Nikon camera for a photo booth?

Yes. BoothLedger tethers Nikon DSLR and Z mirrorless cameras over USB using Nikon's own SDK: guests see a live preview on the screen, BoothLedger takes each photo and the full-resolution JPEG goes straight into your template, printer and sharing. Nikon support is in beta.

Which Nikon cameras work with BoothLedger?

48 Nikon cameras. Full-frame DSLRs: D3, D3S, D3X, D4, D4S, D5, D6, D600, D610, D700, D750, D780, D800, D800E, D810, D810A, D850 and Df. Does the Nikon D3500, D3400 or D3300 work?

How do I set up a Nikon camera for tethering?

Set the camera's USB setting to MTP/PTP and turn off auto power-off. Close any Nikon software that might hold the camera (NX Tether, Camera Control Pro, Nikon Webcam Utility), plug the camera in by USB and select it in BoothLedger. The Nikon software BoothLedger needs is included in the installer.

Do I need NX Tether or Camera Control Pro?

No. BoothLedger controls the camera itself, so you don't need NX Tether, Camera Control Pro or the Webcam Utility. Close them before you start: only one program can control the camera at a time.
